# خدّعها

لعبة خداع وحقيقة جماعية، كل لاعب من جواله، بدون أي مكتبات.

## التشغيل على جهازك
    node server.js
ثم افتح http://localhost:3000

## النشر مجانًا على Render
1. ارفع هذا المجلد إلى مستودع GitHub جديد.
2. في render.com اختر New ← Web Service واربطه بالمستودع.
3. Build Command: (اتركه فارغًا)   Start Command: `node server.js`
4. اختر الخطة المجانية واضغط Deploy.
5. تحصل على رابط مثل https://اسمك.onrender.com، شاركه مع أصحابك.

ملاحظة: الخطة المجانية تنام بعد فترة خمول، فأول فتح قد يتأخر نصف دقيقة.
الغرف محفوظة في ذاكرة الخادم، فإذا أعاد التشغيل تنتهي الألعاب الجارية.
